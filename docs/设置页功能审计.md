## 实现机制

- 页面基类 `_SettingPage`（`pytortoisegit/dialogs/settingsdlg.py`）提供声明式持久化：
  - `_SETTINGS = [(设置键, 控件ID, kind, 默认值)]`，`kind ∈ {bool, int, text, index}`；
  - `_RADIO_GROUPS = [(设置键, [控件ID...], 默认索引)]`。
  - `load_settings()/save_settings()` 由 `SettingsDlg._load_config/_apply` 对每页统一调用。
- 颜色页基类 `_ColorPage`：`_COLORS = [(设置键, 控件ID, 默认#RRGGBB)]`，点击弹 `QColorDialog`，`IDC_RESTORE` 恢复默认。
- 未接线/平台不支持项置灰：页面声明 `_DISABLED`（双平台）或 `_DISABLED_NONWIN`（非 Windows），
  `_SettingPage._apply_disabled` 统一置灰并提示"尚未实现"；Overlays 页在非 Windows 整页置灰。
- git 相关设置（`user.*`、`core.*`、`fetch.prune`、`bugtraq.*`）经 `GitRunner` 写全局 git config；
  其余 UI 偏好写 `QSettings("PyTortoiseGit","PyTortoiseGit")`（键名对齐 TortoiseGit 注册表名）。
- `general_settings()` 是应用级 QSettings 的入口（测试会 monkeypatch 到临时 INI）。
