# 功能测试点（UI）

> 以下按窗口 / 功能列出需要**手动测试**或 **UI 自动化测试**的功能点。
> 「方式」列：**UI 自动** = 可用 pytest-qt 等驱动控件验证；**手动** = 需人工或可视化确认；**手动 / UI 自动** = 两者皆可。

| 模块 | UI 测试点 | 方式 |
|------|-----------|------|
| 主窗口 | 仓库列表：添加 / 删除 / 双击切换 / 重启后恢复 | UI 自动 |
| 主窗口 | 文件夹树：扫描盘符、标记 Git 仓库、展开、刷新 | UI 自动 |
| 主窗口 | 文件夹树 / 内容区右键菜单（仓库、非仓库、空白区、Shift 扩展） | UI 自动 |
| 主窗口 | 内容区：显示子目录与文件、双击进入、前进 / 后退 / 上级 / 刷新 | UI 自动 |
| 主窗口 | 菜单栏命令项与图标、状态栏当前分支 | UI 自动 |
| 主窗口 | 覆盖图标：仓库根绿勾、文件 / 目录的修改 / 新增 / 冲突等状态 | 手动 |
| 日志 Log | 提交列表、分支图（lane）、Action 列图标 | 手动 / UI 自动 |
| 日志 Log | 选中提交显示信息与变更文件、双击比较上一版 | 手动 / UI 自动 |
